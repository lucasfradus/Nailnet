# Dominio

Reglas puras de roles y alcances de la fundación. No hay permisos por defecto: asignaciones inválidas se deniegan. La matriz inicial cubre lectura/administración de sedes y reserva el permiso de usuarios para el siguiente incremento. No habilita pagos, reembolsos ni credenciales.

Profesional tiene alcance propio; como agenda todavía no existe, no recibe acceso administrativo a sedes. No importar este paquete desde el portal público.
